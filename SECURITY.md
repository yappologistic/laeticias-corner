# Security

Laeticia's Corner is a single-player game that runs offline. The places where a security
problem could matter are the files it reads: save files, settings, the catalogs and world data,
and the asset files.

## Reporting a problem

Please report security problems **privately**, never in a public issue or pull request: use
GitHub's private vulnerability reporting on this repository (the **Security** tab, then
**Report a vulnerability**). Say what is affected, how to reproduce it (a file or script that
triggers it is best), and what you think the impact is.

You will get an answer within two weeks. Once a fix is ready it is released and the report is
published with credit to you, unless you ask not to be named.

## Supported versions

Only the latest commit on `main` is supported.
