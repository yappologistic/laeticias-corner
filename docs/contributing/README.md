# Contributor guide

Start with [`CONTRIBUTING.md`](../../CONTRIBUTING.md): the flow (issue first, small pull
requests) and the contribution terms. Then:

1. [Getting started](getting-started.md): build, test and run headless from a clean clone.
2. [Repository map](repository-map.md): what lives where, what is generated, who may change what.
3. [Changing things](changing-things.md): engine code, catalog content, art, audio, world data,
   interface text, each with a checklist.
4. [Testing](testing.md): unit tests, scripted `.lcs` runs, the sanitizer preset, the
   performance gates.
5. [Proof of work](proof-of-work.md): what every issue and pull request must show, and how to
   make screenshots headless ([`shots.lcs`](shots.lcs) is an example script).
6. [AI assistance](ai-policy.md): allowed, always disclosed.
7. [Maintainer's guide](maintainers.md): labels, triage, review, merging, releases, repository
   settings.
